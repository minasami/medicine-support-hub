# Field Contribution Form

Use this form to add or update hospital-channel intelligence. Keep entries short, attributable, and free of patient data or confidential prices.

## Quick Note fields

| Field | Required | Default | Notes |
|-------|----------|---------|-------|
| Account / group | Yes | current page | Select from seed profiles when possible |
| Note type | Yes | Field observation | Field observation / Suggest update / Flag outdated |
| What should a colleague know? | Yes | — | One useful fact |
| Decision layer | No | Unknown | Group / Hospital / Specialty / Operational |
| Role mentioned | No | — | e.g. Chief Pharmacist, Medical Director |
| Confidence | Yes | Medium – field observation | High only with a public source |
| Source URL | No | Field observation | Required for Verified path |
| Date observed | Yes | today | |

## Status after submit
- New users: **Needs review** for high-stakes notes; otherwise **Field-reported**
- Trusted contributors: low-risk notes can publish as **Field-reported** immediately
- Official source + checks passed: may move to **Verified**

## Do not submit
- Patient names or clinical records
- Confidential tender prices or contract terms
- Off-label promotional claims
- Unsourced competitor accusations
